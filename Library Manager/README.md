# Library Manager

Library Manager is a console application written in C++ for managing a collection of books.

## Features

- Add new books
- Display the available books
- Search for a book
- Update book information
- Remove books
- Save information to a file
- Load saved information when the program starts
- Validate user input

## Why I created it

I created this project to practice working with classes, files and user input.

The project helped me understand how information can be added, modified, searched and saved between program sessions.

## How to run it

1. Download or clone the repository.
2. Open `Library Manager.sln` in Visual Studio.
3. Build and run the project.
