# Snake 2.0

Snake 2.0 is a console game written in C++.

The objective is to control the snake, collect food and avoid hitting the walls or the snake's own body.

## Features

- Snake movement controlled from the keyboard
- Random food generation
- Collision detection
- Score tracking
- Increasing snake length
- Saving information to files
- Menu displayed in the console

## Why I created it

I created this project to practice writing a complete program with several connected parts.

While working on it, I learned how to organize game logic, manage movement, detect collisions and separate responsibilities between classes.

## How to run it

1. Download or clone the repository.
2. Open `Snake 2.0.sln` in Visual Studio.
3. Build and run the project.
