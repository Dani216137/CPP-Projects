# C++ Projects

This repository contains several projects created while learning C++ and software development.

The projects helped me practice object-oriented programming, working with files, data validation and organizing code into multiple classes.

## Projects

### Snake 2.0

A console version of the classic Snake game.

The game includes player movement, food generation, collision detection, score tracking and saving information to files.

[View project](./Snake%202.0)

### Library Manager

A console application used to manage a small library.

The user can add, search, update and remove books. The application also saves the information so it can be loaded again later.

[View project](./Library%20Manager)

### Inventory

A simple inventory system inspired by video games.

The program allows objects to be added, moved, stacked and divided into smaller quantities.

[View project](./Inventory)

### Bank Manager

A console-based banking application for managing accounts and performing basic transactions.

The application supports account creation, searching, deletion, deposits, withdrawals, transfers and account status management. It also includes file persistence, transaction logging and input validation.

[View project](./Bank%20Manager)
