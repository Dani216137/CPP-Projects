# Player Battle

Player Battle is a small console application written in C++.

The program simulates a simple fight between two players. Each player has a name, health points and attack damage.

## Features

- Two playable characters
- Health and damage system
- Players can attack each other
- Health cannot go below zero
- The program checks whether a player is still alive
- The winner is displayed when the fight ends
- The user can close the program from the menu

## Why I created it

I created this small project to practice working with classes and objects in C++.

It helped me understand how one object can interact with another object, how constructors work and how data such as health and damage can be managed inside a class.

## How to run it

1. Download the `Player.cpp` file.
2. Open it in Visual Studio or another C++ development environment.
3. Compile and run the program.
4. Follow the instructions displayed in the console.
