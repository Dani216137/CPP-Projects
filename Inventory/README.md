# Inventory System

This project is a simple inventory system written in C++ and inspired by inventory systems found in video games.

## Features

- Add objects to the inventory
- Store object quantities
- Stack compatible objects
- Split a stack into smaller quantities
- Move objects between positions
- Display the inventory contents

## Why I created it

I created this project because I am interested in game development and wanted to understand how an inventory system could work internally.

The project helped me practice classes, object interaction, validation and organizing program logic.

## How to run it

1. Download or clone the repository.
2. Open `Inventory.sln` in Visual Studio.
3. Build and run the project.
